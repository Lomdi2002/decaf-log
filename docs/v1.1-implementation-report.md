## 2. 実装済み機能

- FR-006：1日のカフェイン目標値（mg）の設定
  - 0以上の数値、または「未設定」を許可
  - 負数・数値として扱えない値は保存不可（バリデーションエラー）
  - 入力欄を空にして保存すると `NULL`（未設定）に戻せる
  - 0mgは有効な設定値として扱い、未設定（`NULL`）と混同しない
- FR-007：目標値の保存・表示
  - `/settings` を開いたとき、保存済みの目標値（未設定の場合はその旨）を表示
  - 保存成功時は `/settings` に留まり、「保存しました。」を表示（タイマーによる自動消去はせず、入力変更または次回保存開始時にクリア）
  - 保存失敗時は入力内容を保持しエラーメッセージを表示
- Loading状態（設定値取得中）／Error状態（取得失敗・保存失敗）
- Bottom Navigationへ「設定」を追加（4項目：ホーム／記録／履歴／設定）
- モバイルファーストの維持（横スクロール・文字切れ・操作不能なし）

`docs/requirements.md`・`docs/screen-design.md`のVersion 1.1受け入れ条件、および`docs/implementation-plan-v1.1.md` §16はすべて満たしている。

## 10. 既知の制約

- **`app_settings`のRLSはMVP・デモ用途の暫定構成。** anonロールへ`SELECT`/`UPDATE`のみ許可（`INSERT`/`DELETE`は不許可）。認証がないため、公開URLを知る誰でも目標値を変更できる状態だが、行の追加・削除はできない設計にしてある。
- **同時保存の競合制御（楽観ロック等）は実装していない。** Last write winsとし、`updated_at`は保存のたびに更新される。単一ユーザー・個人利用・デモ用途を前提とする。
- **Vercel PreviewもProductionと同じSupabaseプロジェクトを参照する。** Staging用の別プロジェクトは用意していないため、Preview環境で保存した値も本番Supabaseに反映される。
- Version 1.0から引き続く制約（認証なし、記録編集不可、履歴の日付グループ非対応、`caffeine_records`のRLSがMVP/デモ用途の暫定構成であること）は変更なし。詳細は`docs/mvp-implementation-report.md` §9を参照。
