## 1. 実装した機能

- `/history` に日別カフェイン摂取量グラフ（Rechartsの`BarChart`）を追加
- 今日を含む直近7日間固定表示（横軸：日付、縦軸：mg）
- `consumed_at`をブラウザのローカルタイムゾーン基準の暦日で集計、同日複数記録は合算
- 記録がない日は0mgとして補完。7日間すべて記録0件でもグラフを表示
- Tooltipで各日の実際のmg値を確認可能（純粋関数`formatCaffeineTooltip`で整形し、浮動小数点誤差を丸める）
- Y軸は自動スケール（目標値ラインは表示しない）
- Barのアニメーションは無効化（`isAnimationActive={false}`）
- `DashboardPage`には追加していない（`/history`のみ）

`docs/requirements.md`・`docs/screen-design.md`のVersion 1.3受け入れ条件（§23・§72）は、ローカル環境（テスト・目視確認可能な範囲）ではすべて満たしている。Vercel Preview・Production環境での確認はこれから行う。
