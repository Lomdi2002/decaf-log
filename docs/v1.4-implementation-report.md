## 2. 実装した機能

- FR-010：ダッシュボード（`/`）への連続達成日数カード（`StreakCard`）の追加
  - 達成の定義：その日の合計摂取量（`dailyTotalMg`）が目標値（`daily_caffeine_goal_mg`）以下（`dailyTotalMg <= goalMg`）。目標値ちょうど一致する場合も達成として扱う
  - 今日は連続達成日数の判定に含めない。判定は昨日までを基準とする
  - 記録がない日は0mgとして扱う（正の目標値でも達成扱いになりうる）
  - 判定は`caffeine_records`に存在する最初の記録日より前には遡らない
  - `caffeine_records`に一度も記録が存在しない場合、連続達成日数は0日
  - 目標0mgの場合も特別扱いせず、通常の`<=`比較で判定（0mgなら達成、1mg以上なら未達成）
  - 目標未設定（`NULL`）時：「目標を設定すると連続達成日数を確認できます。」＋`/settings`への導線を表示（`GoalProgress`の導線と表現・UIを統一）
  - 連続達成日数が0日の場合も、特別な文言なしに「連続達成 / 0日」という通常の数値表示
  - `StreakCard`はダッシュボードの既存機能（今日の合計・目標進捗・最近の記録・CTA）を大きく変更しない形で、目標進捗表示の近くに配置

`docs/requirements.md`・`docs/screen-design.md`のVersion 1.4受け入れ条件（§FR-010関連・§73〜§78）はすべて満たしている。

## 3. `calculateStreak`の仕様

`src/lib/streak.js`の`calculateStreak(records, goalMg, referenceDate = new Date())`として実装した。

- **戻り値**：`{ status: 'unset' }`（目標未設定）または`{ status: 'counted', days: number }`（目標設定済み）
- **達成判定**：`totalMg <= goalMg`。目標値ちょうど一致・目標0mgも同じ比較式で扱い、特別な分岐は設けていない
- **日別集計**：`records`を`getLocalDateKey`（Version 1.3で追加済み、`dateUtils.js`）でローカルタイムゾーンの暦日ごとにグループ化し、同日の複数記録は合算する
- **最初の記録日**：全記録の`dateKey`のうち最小のものを`firstRecordDateKey`として求める
- **遡り処理**：`referenceDate`の1日前（昨日）を起点に、1日ずつ過去へ進めながら判定する。未達成の日、または`firstRecordDateKey`より前の日付に到達した時点で終了する
- **記録がない日**：`Map`のデフォルト値（`?? 0`）により自動的に0mgとして扱われる
- **安全装置**：`MAX_ITERATIONS = 100000`（約270年分）という反復回数の上限を設けているが、これは業務上の遡り上限ではなく、万一のロジック不具合による無限ループを防ぐための技術的な安全装置であり、通常利用では到達しない
- `dailyTotals.js`（Version 1.3、直近7日固定の集計）とは独立して実装しており、既存コードには一切手を加えていない

## 13. 既知の制約

- **過去の目標値履歴を保持していない。** `app_settings.daily_caffeine_goal_mg`は現在の目標値のみを保持する
- **現在の目標値を過去の日付にも適用する。** 連続達成日数の計算では、過去の各日付についても現在設定されている目標値を用いて達成判定を行う
- **目標値を変更すると、過去の達成判定と連続達成日数が変化する場合がある。** これは目標値の履歴を保持していないことに起因する既知の制約であり、Version 1.4では意図的に許容している
- 連続達成日数の遡りに業務上の固定上限は設けていないが、無限ループ防止のための安全装置（約270年分の反復上限）を実装に含めている。通常利用でこの上限に到達することはない
- Version 1.0〜1.3から引き続く制約（認証なし、`caffeine_records`のRLSがMVP/デモ用途の暫定構成、記録編集不可、履歴の日付グループ非対応、同時保存の競合制御なし、Rechartsによるバンドルサイズ増加など）は変更なし。詳細は`docs/mvp-implementation-report.md` §9、`docs/v1.1-implementation-report.md` §10、`docs/v1.2-implementation-report.md` §10、`docs/v1.3-implementation-report.md` §13を参照
