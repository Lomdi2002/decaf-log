## 0. 確定済みの仕様方針（ユーザー確定）

1. **達成の定義**：`dailyTotalMg <= goalMg` → 達成、`dailyTotalMg > goalMg` → 未達成
2. **目標未設定（NULL）**：「0日」とは表示せず、「目標を設定すると連続達成日数を確認できます。」等の案内＋`/settings`への導線を表示する
3. **目標0mg**：Version 1.2と同じ意味（0mg → 達成、1mg以上 → 未達成）
4. **今日の扱い**：今日は連続達成日数の判定に含めない。判定は「昨日まで」を基準とする
5. **記録がない日**：0mgとして扱い、目標値以下なら達成とする（Version 1.3の日別集計ルールと揃える）。ただし判定開始日は`caffeine_records`に存在する最初の記録日とし、それより前には遡らない。記録が一度もない場合は連続達成日数を0日とする
6. **表示場所**：Dashboard（`/`）。目標進捗の近くに、大きすぎないシンプルなカードとして表示する（例："連続達成 / 5日"）。Dashboardの既存機能を大きく変更しない
7. **遡る期間**：固定上限は設けない。最初の記録日から昨日までを対象範囲とし、昨日から過去方向へ連続して達成している日数を数え、最初の未達成日に到達した時点で終了する
8. **過去の目標値変更**：目標値の履歴は保持せず、現在の`daily_caffeine_goal_mg`を過去の日付にも適用する。目標値を変更すると過去の判定が変わり連続達成日数が変化しうる（既知の制約として明記）。目標履歴テーブル・日別目標スナップショット・新しいDBテーブル・カラム追加・migration・RLS/GRANT変更は行わない
9. **Version 1.5**：飲み物プリセットはまだ実装しない

## 5. テストすべき境界値

- 目標が`null`（未設定）→ 案内メッセージが表示され、数値としての「0日」は表示されない
- 目標が設定済みだが記録が一度もない → 「0日」
- 昨日が達成、一昨日が達成、3日前が未達成 → 連続達成日数は2日
- 今日の合計が目標を超えていても、昨日以前が達成であれば連続達成日数に影響しない（今日は判定対象外）
- 最初の記録日が「昨日」ちょうどの場合 → 昨日が達成なら1日、未達成なら0日（それより前には遡らない）
- 最初の記録日が「今日」のみの場合（過去の記録が一切ない）→ 連続達成日数は0日
- 目標0mg・ある日の記録が0件（0mg扱い）→ 達成としてカウント
- 目標0mg・ある日の合計が1mg以上 → 未達成としてカウント
- 同じ日に複数記録がある場合、合算した上で目標値と比較する（Version 1.3の合算ロジックと同様）
- タイムゾーン境界（UTCでは前日/翌日にまたがるが、ローカルタイムゾーンでは同日になる記録）で、日別集計・「昨日」の判定がずれないこと

## 6. 仕様上の矛盾や未解決事項

大きな矛盾は見当たらなかったが、実装前に確認したい細部が2点ある。

1. **案内メッセージ・カードの正確な文言**：「目標を設定すると連続達成日数を確認できます。」という文言、カードの見出し「連続達成」＋「◯日」という表記で問題ないか（Version 1.2の`GoalProgress`の「目標を設定する」導線と表現を揃える想定）。
2. **「0日」の見た目**：目標が設定されているが連続達成日数が0日の場合（例：昨日未達成だった場合）も、通常の「連続達成 / 0日」という数値表示のままでよいか、それとも何らかの補足（例：励ましの一言）を加えるか。今回の指示にはないため、追加せず単純な数値表示のみとする想定。

いずれも実装をブロックするものではなく、デフォルト案のまま進めても問題ないと考えているが、念のため記載する。
